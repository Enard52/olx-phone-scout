# Как помочь проекту

Приветствуются баг-репорты с неверно распознанным заголовком, недостающие рыночные цены и починка парсеров.

## Подготовка

```bash
uv sync
uv run ruff check . && uv run ruff format --check . && uv run pytest
```

Тестам сеть не нужна.

## Pull request

- Одно изменение на PR и тест, который без него падает.
- Исправление распознавания бренда или модели идёт вместе с реальным заголовком объявления в тесте.
- Сообщения коммитов: `<type>: <description>`, где type — feat, fix, refactor, docs, test, chore, perf или ci.
- Паузы и повторы запросов берутся из [market-sources](https://github.com/octrow/market-sources); сломанный
  транспорт OLX обычно чинится там.
- Изменения в `README.md` дублируются в `README.ru.md`, и наоборот.

Бережно относитесь к OLX и Kimovil: не ускоряйте запросы и не добавляйте массовый обход.
